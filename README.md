# Pulse

A visualiser for your second screen: every track gets a glowing ring in its own colour that pulses with its level, around a core that breathes with the whole mix, plus glow bars along the bottom. Built by Henry Hoover with SDK Controller.

A LUNA Add On, shared to UA Universe from SDK Controller. Install it from UA Universe or LUNA's Add On Showcase, or open the .lunaaddon in this repository's latest release.
